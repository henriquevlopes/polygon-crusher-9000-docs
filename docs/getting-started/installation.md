# Installation

## Download

Purchase and download the latest `.zip` file from the [Superhive store](#).

!!! warning "Don't unzip the file"
    Blender installs add-ons directly from the `.zip`. Do **not** extract it first.

## Install in Blender

1. Open Blender
2. Go to **Edit → Preferences → Get Extensions**
3. Choose **Install from Disk…**
4. Select the downloaded `polygon_crusher_9000-<version>.zip`
5. Enable the add-on under the **Add-ons** tab if it is not enabled automatically

## Requirements

- **Blender 4.2 or later.** 4.2 is the lowest version the extension accepts
  and has not been tested; the add-on is tested on the newest Blender.
- Windows (x64), Linux (x64), or macOS (Apple Silicon or Intel).
  **Remesh** (the quad tool) works on those. On Linux ARM64 only
  **Decimate** is available, and the panel says the quad engine is not
  available.

## Open the Panel

The add-on has its own tab in the **3D Viewport sidebar**:

- Press **N** to open the sidebar (if it's not visible)
- Click the **Polygon Crusher 9000** tab

(Before 2.8.1 the panel lived in the shared **9000 Toolkit** tab.)

## Updating

To update to a newer version, download the new `.zip` from your Superhive account and install it following the same steps above.
Blender will replace the existing add-on automatically.
