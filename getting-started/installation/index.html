Installation

Download

Purchase and download the latest .zip file from the Superhive store.

Don't unzip the file

Blender installs addons directly from the .zip. Do not extract it first.

Install in Blender

  1. Open Blender
  2. Go to Edit → Preferences → Get Extensions
  3. Choose Install from Disk…
  4. Select the downloaded polygon_crusher_9000-<version>.zip
  5. Enable the addon under the Add-ons tab if it is not enabled automatically

Requirements

  • Blender 4.2 or later. 4.2 is the lowest version the extension accepts and has not been tested; the add-on is tested on Blender 5.2.
  • Windows (x64), Linux (x64 or ARM64), or macOS (Apple Silicon). Intel Macs have no bundled binary.

Open the Panel

The addon panel appears in the 3D Viewport sidebar:

  • Press N to open the sidebar (if it's not visible)
  • Click the 9000 Toolkit tab, then open the Polygon Crusher 9000 panel. It starts collapsed.

Updating

To update to a newer version, download the new .zip from your Superhive account and install it following the same steps above.
Blender will replace the existing addon automatically.
