Installation

Download

Purchase and download the latest .zip file from the Superhive store.

Don't unzip the file

Blender installs addons directly from the .zip. Do not extract it first.

Install in Blender

  1. Open Blender
  2. Go to Edit → Preferences → Add-ons
  3. Click Install from Disk…
  4. Select the downloaded polygon_crusher_9000_*.zip
  5. Enable the addon by ticking the checkbox next to Polygon Crusher 9000

Requirements

  • Blender 4.2 or later (tested on 5.1)
  • Windows, macOS, or Linux

Open the Panel

The addon panel appears in the 3D Viewport sidebar:

  • Press N to open the sidebar (if it's not visible)
  • Click the Crusher tab

Updating

To update to a newer version, download the new .zip from your Superhive account and install it following the same steps above.
Blender will replace the existing addon automatically.
